# Treino Ricardo — documentação completa

Versão arquivada em 10/11/2026. Código de origem: 79415d2e7ae3fa041576fe6555cb3cd04a6ec8dd.

Revisão visual aplicada em 10/11/2026 sobre esse código: tema galáctico, novo layout, 29 ilustrações redesenhadas e marcação de exercícios concluídos. A rotina (dias, exercícios, séries e pausas) não foi alterada. Os detalhes estão na seção 12.

## 1. Objetivo e decisões do projeto

Transformar a rotina de treino em um app web simples, acessível pelo celular e adicionável à tela inicial. A rotina distribui os grupos ao longo da semana e repete peito/bíceps e costas/tríceps em três dias. A estrutura evoluiu para seis exercícios e, na revisão final, sete por sessão, com liberdade para selecionar a composição.

A configuração final utiliza três exercícios do bloco principal e dois de cada um dos dois blocos secundários. Nos dias de segunda a sábado, são três séries em cada exercício principal e duas em cada secundário: 17 séries por sessão. No domingo, todos recebem duas séries: 14 séries. O domingo é opcional e leve.

O alvo de duração é aproximadamente 55–60 minutos, incluindo oito minutos de aquecimento, cerca de 42–47 minutos de exercícios, pausas e trocas, e até cinco minutos de volta à calma. É uma estimativa, sem garantia de duração exata. Não é necessário prolongar uma sessão concluída antes.

A interface orienta deixar 2–3 repetições em reserva, ou 3–4 nos blocos leves. Os avisos de boxe e recuperação estão transcritos nos respectivos dias. Este arquivo documenta a rotina configurada; não representa nova avaliação física.

## 3. Como usar o app, passo a passo

1. Acesse https://treino-ricardo-semana.orderlycove1.chatgpt.site com a conta autorizada.
2. O app seleciona inicialmente o dia atual no fuso America/Sao_Paulo. Toque em outro dia para consultar sua sessão.
3. Leia o grupo, a duração e eventuais observações.
4. Faça o aquecimento e siga os sete cartões na ordem apresentada.
5. Consulte as séries e repetições de cada cartão.
6. Cada cartão mostra a ilustração do movimento (início e fim, com o músculo trabalhado em destaque), o nome, as séries × repetições e dois botões.
7. Toque no botão com os segundos para iniciar o descanso. Um novo descanso substitui o anterior. A barra do cronômetro mostra o tempo restante.
8. Use Pausar/Continuar para controlar o cronômetro; ao zerar, aparece “Pode voltar”. Concluir ou o botão de fechar encerra o contador.
9. Toque no botão de check do cartão para marcar o exercício como concluído. O anel no topo da página mostra quantos exercícios do dia já foram feitos.
10. Abra “Sobre este treino” para consultar as orientações e o link da planilha, e “Como instalar” para ver como adicionar o app à tela inicial.

No computador, a barra lateral lista os sete dias como uma constelação, com os grupos de cada dia. No celular, essa lista vira uma faixa horizontal no topo, com os dias abreviados. Os exercícios aparecem agrupados por bloco: o principal (três exercícios) e os complementares (dois exercícios cada).

O cronômetro usa o horário final salvo no navegador. Ao retornar à página, recalcula o restante. Há apenas um cronômetro. A marcação de concluídos é salva por dia no aparelho e reinicia na virada do dia (fuso America/Sao_Paulo). Não existem registro de cargas, histórico de sessões nem alerta sonoro implementados.

A aplicação usa HTML, CSS e JavaScript nativos. Não tem dependências de execução, etapa de compilação, servidor de aplicação ou banco de dados. O navegador busca workouts.json e monta os cartões. Cada campo image aponta para images/<identificador>.svg.

### Dados e persistência

A chave localStorage “ricardo-rest” armazena o estado do descanso (end, remaining, total e paused). A chave “ricardo-done” armazena a data e os exercícios marcados como concluídos em cada dia; ela é descartada quando a data muda. Ambas ficam no navegador/dispositivo atual, sem sincronização entre aparelhos. O treino é arquivo estático compartilhado pela versão hospedada. O dia selecionado não é salvo.

### Funcionamento sem rede e atualizações

O service worker usa o cache “ricardo-workout-v4”. Na instalação, armazena a página, estilos, scripts, JSON, manifesto, ícones, fontes, fundo estrelado e imagens referenciadas. Nas consultas tenta primeiro a rede e usa cache se a requisição falhar. Uma resposta HTTP de erro não é tratada como falha de rede no código atual. O cache não é atualizado a cada consulta.

O uso offline exige que a primeira visita e o cache tenham concluído com sucesso; autenticação da hospedagem e políticas do navegador podem interferir. Os caches anteriores com prefixo ricardo-workout- são apagados na ativação de uma nova versão. Ao alterar o conteúdo, incremente o identificador de cache em sw.js para renovar os arquivos offline.

## 6. Executar em outro computador

1. Extraia o ZIP mantendo as pastas.
2. Instale Python 3, se ainda não estiver disponível.
3. Abra um terminal na pasta Treino_Ricardo.
4. Execute: `python -m http.server 8000 --directory app` (em alguns sistemas, use python3).
5. Abra http://localhost:8000 no navegador.
6. Para encerrar, pressione Ctrl+C no terminal.

Evite abrir index.html diretamente por duplo clique: o carregamento de JSON e o service worker dependem de um servidor HTTP. Localhost permite testar o service worker; para acesso remoto e instalação, hospede com HTTPS. O servidor simples acima é para teste local.

## 7. Editar os treinos

1. Faça uma cópia do pacote antes de editar.
2. Abra app/workouts.json em um editor de texto UTF-8.
3. Preserve a lista de sete objetos, na ordem segunda a domingo.
4. Edite name (dia), time (texto de duração), groups (título), note (aviso) e exercises (lista de exercícios).
5. Para cada exercício, mantenha name, sets (texto), rest (número em segundos) e image (nome do SVG sem extensão).
6. Mantenha sete exercícios por dia. Os três primeiros formam o bloco principal. O texto de groups deve seguir o formato “Grupo (3) + grupo (2) + grupo (2)”, pois o app usa esses números para dividir o dia em blocos.
7. Se adicionar uma imagem, coloque o SVG em app/images e use seu nome exato no JSON. Para seguir o estilo atual, crie uma função ex_<nome>(s) em tools/gerar_ilustracoes.py (s = 0 início, s = 1 fim) e rode `python tools/gerar_ilustracoes.py <nome>`.
8. Atualize também os textos gerais em index.html e no diálogo “Sobre este treino” em app.js se mudar duração, divisão ou séries.
9. Incremente a versão do cache em app/sw.js.
10. Execute `python verificar.py`, teste localmente e publique novamente.

Exemplo de exercício:

```json
{"name":"Rosca Scott (máquina)","sets":"2 × 8–12","rest":90,"image":"scott"}
```

As séries e repetições são textos exibidos; o app não calcula automaticamente volume ou duração ao alterá-los.

## 8. Hospedar e transferir para outro local

1. Escolha uma hospedagem capaz de servir arquivos estáticos por HTTPS.
2. Configure a pasta app como diretório publicado; o index.html deve ficar na raiz do endereço desejado.
3. Publique todos os arquivos dessa pasta, mantendo images e os nomes relativos.
4. Confira se workouts.json e os SVGs abrem sem erro e se o servidor entrega JS, JSON e manifesto com tipos adequados.
5. Abra o site no celular e confira sete exercícios em cada um dos sete dias, imagens e cronômetro.
6. Faça nova instalação na tela inicial usando o novo endereço.

A cópia exportada não inclui contas, credenciais, permissões ou configuração de acesso da hospedagem atual. O endereço atual tem acesso restrito ao proprietário; compartilhar o ZIP permite hospedar uma cópia independente. Defina o acesso da nova hospedagem de acordo com o público pretendido. Preferir servir na raiz do domínio; revise start_url e scope do manifesto antes de usar subpastas.

O estado do cronômetro do endereço anterior não é transferido automaticamente para outro domínio. Este ZIP inclui o código pronto para hospedagem, sem o histórico Git nem arquivos internos da plataforma.

### Como as ilustrações são feitas

Cada figura usa um esqueleto com ossos de tamanho fixo (tronco, coxa, canela, braço, antebraço). Os membros que tocam um aparelho usam cinemática inversa, então o pé ou a mão ficam sempre no ponto certo. O músculo trabalhado aparece com brilho dourado e rosado. Cada exercício é uma função com dois estados (início e fim) em tools/gerar_ilustracoes.py. Para regenerar todas: `python tools/gerar_ilustracoes.py`. Para uma só: `python tools/gerar_ilustracoes.py press`. Os ícones e o fundo estrelado são regenerados com `python tools/gerar_assets.py` (os PNGs exigem Playwright).

### Limites conhecidos

- As figuras são esquemáticas, em perfil ou de frente, e simplificam equipamentos. Servem como lembrete do movimento, não como instrução técnica de execução.
- A planilha continua sem sincronização automática com o app.
- O serviço de cache continua tratando resposta HTTP de erro como resposta válida (comportamento herdado, não alterado nesta revisão).
- Não há aviso sonoro nem vibração no fim do descanso.
