# Comece por aqui

Pacote completo do app Treino Ricardo — 10/11/2026, com a revisão visual galáctica (ilustrações novas, layout de sistema, check de concluídos).

1. Leia DOCUMENTACAO_COMPLETA.html no navegador ou DOCUMENTACAO_COMPLETA.md no editor.
2. O código pronto para hospedagem está em app/.
3. Para testar: python -m http.server 8000 --directory app
4. Abra http://localhost:8000.
5. Para conferir os arquivos: python verificar.py
6. Para regenerar as ilustrações: python tools/gerar_ilustracoes.py (detalhes na seção 12 do manual).

O manual contém todos os 49 exercícios, a descrição do novo visual, séries, pausas, avisos, instalação no celular, funcionamento, edição e transferência. SHA256SUMS.txt permite conferir integridade. A planilha original não integra o ZIP e não sincroniza automaticamente.
